# 架构和验证范围

`gccp` 接受业务身份，检查当前版本和工程。原生桥以会话限定的本机请求进入 Qt 应用线程，在唯一的预算表上下文调用固定动作。桥只导出一个入口，写入动作需要预先记录的意图。执行器重新读取模型，校验目标变化并检查非目标预算行。结果不确定时保留原命令，禁止自动重发。

| 功能 | 实机验证 | 范围 |
| --- | --- | --- |
| 插入、改量、保存、回读 | 3-199（量1）、3-200（量1）、3-201（量2） | 同一已打开测试工程，3-201 通过参数化单命令完成 |
| 临时删除 | 3-201 保留原行、删除线、工程量和合价归零 | 同一工程，非目标行通过对照 |
| 永久删除 | 原生确认提交一次，目标和两条主材子行移除 | 现场通过原命令续接完成；同一调用内自动确认的编排用离线测试覆盖 |
| 防重 | 套项、临时删除、永久删除和确认重试 | 相同命令只返回回执，新增派发为零 |

实机记录来自原生主线。公开版在拆包和路径调整后对 Python 测试、wheel 和原生编译单独验证。保存后的验证是当前进程完整模型回读加文件检查，未作自动关闭重开认证。软件计价原值和正常零价均保留。
