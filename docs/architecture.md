# 架构和验证范围

`gccp` 接受业务身份，检查当前版本和工程。原生桥以会话限定的本机请求进入 Qt 应用线程，在唯一的预算表上下文调用固定动作。桥只导出一个入口，写入动作需要预先记录的意图。执行器重新读取模型，校验目标变化并检查非目标预算行。结果不确定时保留原命令，禁止自动重发。

| 功能 | 实机验证 | 范围 |
| --- | --- | --- |
| 顶层套项、首次填量、保存、回读 | 3-199（量1）、3-200（量1）、3-201（量2） | 同一已打开测试工程，3-201 通过参数化单命令完成 |
| 二级分部套项及首次填量 | Rev16 接收井洞门、独立对撑、管内 C25 垫层、外运等代表项 | 核对完整分部路径、数量和工料机。0.2 自动使用已有的无保存路径 |
| 定额复制、改主材及填量 | DN500 管件一次原生复制并连续向下粘贴两次，主材各自重新编码，工程量分别读回 | 同一分部普通定额，零价且未锁量的目标主材。保存由操作者安排 |
| 补充子目 | 闭水、涂层和管卡已实际提交。0.1.0a11 验证自动打开、填字段和取消 | 零价单条。自动打开并实际提交的组合仍待授权工程验证 |
| 指定标准换算 | `11-34`、50 m，人工及机械 1.15，工料机核对通过 | 支持这一条内置规则。其他系数和材料替换按各自原生动作验证 |
| 调价后刷新 | Rev16 同进程按新 GPB7 摘要刷新 | 核对同一预算树，只接受价格字段变化；改价本身由操作者执行 |
| 临时删除 | 3-201 保留原行、删除线、工程量和合价归零 | 同一工程，非目标行通过对照 |
| 永久删除 | 原生确认提交一次，目标和两条主材子行移除 | 现场通过原命令续接完成；同一调用内自动确认的编排用离线测试覆盖 |
| 防重 | 套项、临时删除、永久删除和确认重试 | 相同命令只返回回执，新增派发为零 |

实机证据来自固定安装的一套 GCCP7 环境。0.1.0a11 在全新的本机 Python 3.12 环境中从 wheel 安装，通过版本、依赖、`doctor` 和随包索引查询检查。45 项应用层离线测试通过。保存后的已验证范围为当前进程完整模型回读与磁盘检查。

通用候选通道通过 `quota-candidates` 读取软件实际编号、完整名称、单位和专业，`quota-run` 在写入前重新核对。本机安装的 12,244 条原厂索引供搜索定位；实际写入覆盖范围以上表及现场唯一候选为准。当前单表只读快照有 500 行上限，单观察器运行包有 48 次调用上限，跨分部导航有 32 步上限。大型工程需另外验证分段读取与精确定位。

## 发布验收

**0.2 限定环境试用版**覆盖已匹配指纹的 Windows GCCP7 北京 2025 概算环境。主流程是原厂索引查项、现场校验、套入并填量和读回。普通套项完成后由操作者或广联达安排保存。中断或结果未知时保留原回执，由操作者判断。主动保存及自动恢复属于单独的能力范围。

**稳定版验收**以已承诺的操作范围为准。用独立工作站和授权测试工程跑通安装、绑定、查项、二级分部套入、补项和单行删除，验证人工核对流程可执行。确定公开命令、参数、JSON 字段和错误码语义，验证升级后还能读旧账本和旧回执。对外分发前确认原厂索引的可分发范围，见[来源与依赖](../THIRD-PARTY-NOTICES.md)。

**后续扩展**包括已有行独立改量、分部增删改、批量工料机与价格调整。支持更多广联达版本时，用单独的组件指纹配置和实机测试记录。
