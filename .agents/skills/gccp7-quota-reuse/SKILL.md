# 复用广联达定额

先用同目录的 `gccp7-native-cli` 技能找到本机命令、绑定已打开的目标工程、读回预算。用 `gccp --version` 和 `gccp quota-clone --help` 核对能力。使用说明在主技能的 `references/docs/quota-reuse.md`，源码仓库内也可读 [定额复用](../../../docs/quota-reuse.md)。

1. 先检查已有定额及其主材。按专业、库、工作内容、施工方式和计量单位确认哪些工作适用同一定额。相同口径只用于缩小候选范围。已有正确行保留，疑似重复或量错的逐行确认。
2. 找到已核定的普通定额作为源行。需要首套时用 `quota-run`。在预算书“整个项目”选中定额父行，保持“工料机显示”开启，记下完整分部路径、定额号、含标记的完整定额名称、单位和拟更名主材的当前编码。
3. 用 `quota-clone` 在同分部紧接源行追加。单条传 `--material-name` 和 `--quantity`。多条传 `--variants`，内容为 `[{"material_name":"已核定的新主材名称","quantity":"2"}]`，每批最多 5 条。命令复制一次，顺序粘贴并逐条读回。工程量按定额单位填写。
4. 核对源行和其他预算行、每条新增行的落点、主材新编码、名称、工程量和计价。允许广联达为改名主材自动生成编码。当前入口支持给零价且未锁量的既有主材直接改名，原厂材料库选材替换需另行核验。
5. 保存按用户安排。发现部分结果、超时或状态未知时，用原命令号查 `command-status`，对照返回的 `clones` 和实时预算后由操作者判断。原生复制期间保持当前广联达选区和剪贴板。
